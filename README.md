## **MERN E-Commerce App – Microservice Architecture**  

**Live Demo:** [https://ecommerce-app-xdig.onrender.com/](https://ecommerce-app-xdig.onrender.com/)

## Description
A MERN stack e-commerce application built using **microservice architecture** to practice modular backend design. It includes `user`, `cart`, `products`, and `order` services with JWT authentication. Full Frontend and admin dashboard are planned.

## Features
- Microservice backend architecture
- JWT authentication
- RESTful APIs for user, cart, products, and orders
- Scalable design for future expansion
- Planned: admin dashboard, Stripe payments, product catalog

## Technologies
- Backend: Node.js, Express.js, MongoDB
- Frontend: React.js
- Authentication: JWT
- Deployment: Render
