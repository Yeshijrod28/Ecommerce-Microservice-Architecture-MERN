MERN E-Commerce App – Microservice Architecture

Live Demo: https://ecommerce-app-xdig.onrender.com/

Description:
A MERN stack e-commerce application built using microservice architecture to practice modular backend design. Currently, it has the base architecture with four backend services: user, cart, products, and order. JWT authentication is implemented for secure user sessions.

Planned future enhancements include an admin dashboard, Stripe payment integration, and adding product listings.

Features (Current)

Microservice Architecture: Separate services for users, cart, products, and orders

JWT Authentication: Secure login and signup

RESTful APIs: Basic endpoints for each service

Scalable Design: Ready for future expansion with admin panel, product management, and payments

Technologies Used

Backend: Node.js, Express.js, MongoDB

Frontend: React.js

Authentication: JWT

Architecture: Microservices

Deployment: Render

Future Enhancements

Admin dashboard for product and order management

Stripe payment integration

Product catalog with images and categories

Full frontend implementation

Notes

This is primarily a backend practice project focusing on microservice architecture

No products or frontend implemented yet

Great foundation for building a full-fledged e-commerce platform
